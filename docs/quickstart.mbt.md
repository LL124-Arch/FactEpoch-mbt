# Quickstart

> **Not available yet.** This repository does not contain a MoonBit module, so publishing sample code here would create an uncheckable promise.

The first executable quickstart will be added together with the public root API. Its fenced MoonBit snippets will be compiled in CI and will demonstrate, with fixed IDs and Unix-millisecond timestamps:

1. creating a `MemoryGraph`;
2. recording an episode and two entities;
3. asserting a fact;
4. explicitly superseding it;
5. querying the same `valid_at` under two `known_at` values;
6. explaining the source and replacement chain;
7. encoding, decoding, and verifying canonical JSONL.

Until those checks exist, [the design contract](design.md) is the authoritative API plan and the README truthfully reports design-only status.
